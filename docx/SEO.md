## 五、FAQ（放 Modrinth Description 最底部）

Google 很愛吃問答格式，容易出現在搜尋摘要與 People also ask。

### 繁中

**atrain 是什麼插件？**
atrain 是 Minecraft Paper 伺服器用的火車與站點插件。用金磚和鐵軌就能建站，蹲下右鍵開啟 GUI，不需要記複雜指令。

**atrain 支援哪個版本？**
需要 Paper 1.21 以上與 Java 21 以上。

**atrain 怎麼讓礦車變成列車？**
把多台礦車放在相鄰軌道上，插件會自動連結成一列。直線以設定速度巡航，彎道與上下坡會自動減速。

**atrain 可以自動停車嗎？**
可以。在 config.yml 開啟 auto_stop 後，列車進站會整列停靠，倒數結束後整列自動發車。

**atrain 需要指令建站嗎？**
不需要。金磚上方鋪鐵軌，蹲下右鍵金磚即可建立與編輯站點。管理員也可使用 /train 開啟管理介面。

**atrain 和原版礦車有什麼不同？**
預設會控速、連結、可選自動停車。若想要原版物理，將 train_control 設為 false 即可。

**atrain 有中文介面嗎？**
有。支援繁體中文、簡體中文、英文、日文，可用 /lang 切換。

### English

**What is atrain?**
atrain is a Minecraft Paper plugin for train and station gameplay. Create stations with gold blocks and rails using sneak right click GUI setup with no complex commands.

**What Minecraft version does atrain support?**
Paper 1.21 or newer with Java 21 or newer.

**How do minecarts become a train in atrain?**
Place multiple minecarts on adjacent rails and the plugin auto couples them into one consist with cruise speed on straights and slowdown on curves.

**Does atrain support automatic station stops?**
Yes. Enable auto_stop in config.yml for full consist dwell time and automatic departure.

**Do I need commands to build stations?**
No. Place rails on a gold block and sneak right click to create and edit stations. Admins can also use /train for the management GUI.

**How is atrain different from vanilla minecarts?**
By default it adds speed control coupling and optional auto stop. Set train_control to false for vanilla physics.

**Does atrain support Chinese?**
Yes. Traditional Chinese Simplified Chinese English and Japanese are supported via /lang.
