# atrain — 金磚站點與連結列車控速

## 摘要（貼到 Modrinth Summary，純文字單行）

atrain 是 Minecraft Paper 1.21 火車與礦車站點插件，金磚零指令建站，礦車自動連結成列車，支援自動停車進出站、彎道減速、軌道錄製與多語言，適合鐵道 RPG 與生存伺服器

---

## 完整介紹（貼到 Modrinth Description）

在 Minecraft 伺服器裡打造有站名、方向、進出站感的鐵道體驗，不用背指令，蹲下右鍵金磚就能建站、調整站點資訊；礦車還能自動連結成列車，直線滿速、彎道減速，整列進站停靠後自動發車。

atrain 是一款專為 Minecraft Paper 伺服器設計的火車插件與礦車站點插件。如果你正在找不用指令就能建站、礦車自動連結成列車、進出站自動停車的鐵道系統，atrain 用金磚站點加鐵軌即可完成設定，適合鐵道 RPG、城市生存、捷運模擬與觀光路線伺服器。

---

## 為什麼選 atrain？

- **零指令建站**：金磚 + 鐵軌，蹲下右鍵開 GUI 就能設定站名、上下一站、重點站與行駛方向
- **沉浸式資訊顯示**：站在金磚上，actionbar 即時顯示上一站／本站／下一站
- **連結列車控速**：多台礦車相鄰自動連成一列；直線巡航、彎道與上下坡自動減速
- **可選自動停車**：開啟後整列進站停留，倒數結束整列自動發車，乘客看得到提示
- **軌道錄製與導引**：錄製完整路線軌跡，之後可沿軌跡快速行駛（cinematic transit）
- **多語言**：繁中、簡中、英文、日文介面

想回歸原版礦車物理？關掉 `train_control` 即可。

## 快速開始

1. 下載 `atrain-x.x.x.jar`，放入 `plugins/` 資料夾
2. 重啟伺服器
3. 金磚上方鋪鐵軌 → **蹲下 + 右鍵** 開啟站點 GUI
4. 設定站名、方向；旁邊可放鑽石塊作調速方塊（鐵軌正下方）
5. 放礦車上軌——相鄰礦車會自動連結，直線跑滿速、彎道自動減速
6. （可選）在 `config.yml` 開啟 `auto_stop`，整列進站自動停靠

## 核心功能一覽

### 站點資訊（金磚）
- actionbar 顯示上一站／本站／下一站
- 重點站標記、行駛方向（例：台北 → 南下）
- 管理員備註（僅 OP 可見）
- 已註冊金磚受保護，需權限才能拆除

### 調速方塊（鑽石塊）
- 放在**鐵軌正下方**，礦車經過即加減速
- 蹲下右鍵開 GUI 設定速度

### 連結列車
- 直線：`cart_speed` 巡航滿速
- 彎道／上下坡：自動降至 `curve_speed`
- 建議 4 節車廂，相鄰自動連結
- 搭配自動停車：整列停靠、整列發車

### 軌道錄製
- 管理 GUI 可開始／停止錄製
- 錄製時以原版物理跑完整條路線，每站停留 4 秒
- 完成後站點導引沿儲存軌跡行駛

### 懸浮軌道（可選）
- `hang_rail.enabled: true` 啟用
- 礦車在鐵欄杆下方穩定懸浮，維持巡航速度

## 權限（預設僅 OP）

| 權限 | 說明 |
|------|------|
| `atrain.admin` | 管理員全權 |
| `atrain.gui` | 開啟 `/train` 管理介面 |
| `atrain.station.edit` | 蹲下右鍵編輯金磚站點 |
| `atrain.speed.edit` | 蹲下右鍵編輯調速鑽石塊 |
| `atrain.cart.spawn` | 站點右鍵召喚礦車 |
| `atrain.block.break` | 拆除已註冊站點與調速方塊 |

可用 LuckPerms 等插件開放給特定身分組。
