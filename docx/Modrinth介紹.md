# atrain — 金磚站點與連結列車控速

## 摘要（貼到 Modrinth Summary，純文字單行）

atrain 是 Minecraft Paper 1.21 火車與礦車站點插件，金磚零指令建站，支援 BlueMap 線上地圖、A* 瞬間取徑錄製、多玩家防重疊連結與自動停車，適合鐵道 RPG 伺服器

---

## 完整介紹（貼到 Modrinth Description）

在 Minecraft 伺服器裡打造有站名、方向、進出站感的鐵道體驗，不用背指令，蹲下右鍵金磚就能建站、調整站點資訊；礦車還能自動連結成列車，直線滿速、彎道減速，整列進站停靠後自動發車。

atrain 是一款專為 Minecraft Paper 伺服器設計的火車插件與礦車站點插件。如果你正在找不用指令就能建站、礦車自動連結成列車、進出站自動停車的鐵道系統，atrain 用金磚站點加鐵軌即可完成設定，適合鐵道 RPG、城市生存、捷運模擬與觀光路線伺服器。

---

## 為什麼選 atrain？

- **零指令建站**：金磚 + 鐵軌，蹲下右鍵開 GUI 設定站名、方向與多重點站互聯
- **線上地圖整合**：支援 BlueMap，即時在網頁地圖顯示站點位置與 3D 路線軌跡
- **沉浸式資訊顯示**：ActionBar 即時顯示上一站／本站／下一站，聊天欄動態提示去回程轉乘資訊
- **連結列車與防重疊**：多人同站召喚礦車自動尋找空位防重疊，相鄰自動連成一列；直線巡航、彎道自動減速
- **A* 自動軌道錄製**：內建 A* 演算法瞬間完成兩站間最高十萬格的自動取徑，並支援手動跑圖錄製
- **多語言**：繁中、簡中、英文、日文介面

想回歸原版礦車物理？原版礦車不受插件接管，或關掉 `train_control` 即可。

## 快速開始

1. 下載 `atrain-x.x.x.jar`，放入 `plugins/` 資料夾（如有 BlueMap 可一併安裝）
2. 重啟伺服器
3. 金磚上方鋪鐵軌 → **蹲下 + 右鍵** 開啟站點 GUI
4. 設定站名、方向；旁邊可放鑽石塊作調速方塊（鐵軌正下方）
5. 放礦車上軌——相鄰礦車會自動連結，直線跑滿速、彎道自動減速
6. （可選）在 `config.yml` 開啟 `auto_stop`，整列進站自動停靠

## 核心功能一覽

### 站點資訊（金磚）
- ActionBar 顯示上一站／本站／下一站，依月台側自動反轉去回程
- 支援多重點站雙向互聯，進站時聊天欄動態提示轉乘資訊
- 管理員備註與獨立的站點排序 GUI
- 已註冊金磚受保護，需權限才能拆除

### 線上地圖整合（BlueMap）
- 自動同步站點標記（POI）與路線 3D 軌跡至網頁地圖
- 路線軌跡依據設定的聊天顏色即時渲染

### 連結列車與防重疊
- 多人同時上車自動尋找相鄰空鐵軌生成，防止重疊
- 直線：巡航滿速；彎道／上下坡：自動減速
- 相鄰礦車自動連結，搭配自動停車可整列停靠、發車
- 專屬 PDC 標籤，不干擾玩家手動放置的普通礦車物理

### 軌道錄製與導引
- **A* 自動取徑**：兩點間瞬間計算並儲存軌跡（最高支援十萬格）
- **手動錄製**：乘坐礦車跑完路線，防呆偵測中途下車自動取消
- **智能軌跡保留**：變更路線站點順序時，自動保留未斷鏈的軌跡段落
- 導引模式沿軌跡平滑行駛，到站精準停靠

### 調速方塊與懸浮軌道
- **調速鑽石塊**：放鐵軌正下方，右鍵設定經過加減速
- **懸浮軌道**：礦車在鐵欄杆下方維持巡航懸浮行駛

## 權限（預設僅 OP）

| 權限 | 說明 |
|------|------|
| `atrain.admin` | 管理員全權 |
| `atrain.gui` | 開啟 `/train` 管理介面 |
| `atrain.station.edit` | 蹲下右鍵編輯金磚站點 |
| `atrain.speed.edit` | 蹲下右鍵編輯調速鑽石塊 |
| `atrain.cart.spawn` | 站點右鍵召喚礦車 |
| `atrain.block.break` | 拆除已註冊站點與調速方塊 |

可用 LuckPerms 等插件開放給特定身分組。
