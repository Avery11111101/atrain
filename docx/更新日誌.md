# 更新日誌

## v1.6.0 (2026-07-14)
- **BlueMap 整合**：線上地圖即時顯示站點標記與 3D 軌跡，並依照路線顏色渲染。
- **介面優化**：重點站轉乘資訊從 ActionBar 移至聊天欄，並支援動態顯示去回程目的地。
- **路線與軌跡管理升級**：
  - 新增獨立站點排序 GUI，支援左右鍵直覺調整。
  - 支援「多選重點站」，且各站點雙向互聯綁定。
  - 實裝「自動取徑錄製」，兩站間直線不再需要用實體礦車跑，瞬間完成路線錄製。
  - **軌跡儲存架構分離**：將 `lines.yml` 臃腫的座標點資料拆分為獨立檔案，存於 `plugins/atrain/routes/`（格式：`去程ID_回程ID.yml`），大幅減輕設定檔負擔。
  - 將自動尋路演算法從 BFS 升級為高效能的 **A* 演算法**，最高支援 **100,000** 格的超長距離掃描，徹底解決長路線掃描失敗導致移動異常的問題。
  - 錄製段落選擇 GUI 支援直接刪除不需要的段落軌跡。
- **效能優化與修復**：
  - 將每 Tick 全域掃描礦車改為事件觸發的快取清單維護，大幅降低伺服器負載。
  - 修復站點順序變更或合併時可能造成的軌跡錯亂與伺服器崩潰。
  - GUI 存檔還原至主執行緒，避免並行寫入風險 (CME)。
  - 修復去回程月台判定邏輯，現在站內 ActionBar 能夠準確依據玩家所在的月台側（去/回）正確反轉顯示上一站與下一站。
  - 站點編輯 GUI 新增「傳送至另一側月台」的終界珍珠快捷按鈕。

## v1.5.5 (2026-07-13)
- **原版物理相容**：新增 PDC 實體標籤過濾，徹底解決玩家手動放置的普通礦車被插件強制接管的問題。
- **邏輯修復**：修復終點站玩家上車後仍能開走礦車的漏洞。
- **底層升級**：全面改用 Adventure Component API，移除所有過時 API 以完整相容 Paper 1.21+ (26.2)。
- **路線導引修復**：修復未加載區塊計算路徑的無限迴圈卡死問題、修復座標解碼負數遺失問題、以及修復到站不自動停留與切段的問題。
- **體驗優化**：`/train reload` 提示只會發送給管理員，減少一般玩家干擾；優化 PlayerMoveEvent 金磚站點查詢效能。


- **玩家教學**：新增 `docx/玩家教學.md`；遊戲內 `/train gui` → 教學指南新增「乘車體驗」，並更新快速開始、自動停車等文案以對齊站點導引機制
- **文件整理**：更新日誌移至 `docx/更新日誌.md`；新增 Modrinth 中英文介紹、SEO 文案包
- **建置環境**：Gradle 升至 9.1（支援 Java 25 執行建置）；Shadow 插件改為 `com.gradleup.shadow`；新增 Java 21 toolchain 自動下載

## v1.4.0
- **軌道錄製**：GUI 主選單「軌道錄製」與路線詳情可開始/停止錄製
- 錄製時礦車以**原版物理**沿軌道跑完整條路線，每站停留 4 秒後自動發車
- 錄製完成後，站點導引（cinematic transit）沿儲存的軌跡快速行駛

## v1.5
- **鑽石塊改用途**：鐵軌正下方 = 調速方塊（蹲下右鍵 GUI 設速度，經過即加/減速）
- 站點資訊顯示改為僅站在金磚上查看

## v1.0
- 上車自動發車：在站點坐上礦車即往面向方向自動開走（僅對靜止礦車，行駛中上車不干擾）
- 到站自動停留：`settings.auto_stop` 預設開啟，到站停留 `default_dwell_time` 後自動再發車
- 充能鐵軌加速：列車經過「已通電的充能鐵軌」時飆到 `settings.boost_speed`（預設 1.0），平常維持一般巡航
- 可用 `settings.powered_boost` 開關此機制
- 懸浮軌道改為每 tick 主動吊住，礦車在鐵欄杆下方可穩定懸浮不再墜落（靜止也吊住）
- 懸浮段維持巡航速度，不會滑行到停
- 轉彎/上下坡「提前減速」：新增 `settings.curve_lookahead`（預設 5 格）
- 新增連結列車控速：`cart_speed` 巡航滿速、彎道/上下坡自動減速至 `curve_speed`
- 相鄰礦車自動連結成一列，搭配自動停車可整列停靠、時間到整列自動發車
- 車上乘客顯示停靠倒數與發車提示
- 可用 `settings.train_control: false` 回歸原版物理
- 金磚站點資訊顯示（上一站/本站/下一站/重點站/方向）
- 蹲下右鍵零指令建站與編輯
- 管理員備註專區
- 可選自動停車（預設關閉）
- 多語言介面
