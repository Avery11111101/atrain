# 更新日誌

## v2.0.0-beta.2 (2026-09-13)
- **修復列車離站與進站移動卡頓不連貫問題 (#1)**：
  - **平滑高度貼軌 (`snapToRailHeight`)**：徹底解決原先路徑取樣強制將礦車 X/Z 座標吸附至方塊中心導致的低速格狀瞬移與停滯問題，支援連續高精度浮點位移與爬升坡度平滑過渡。
  - **進出站過渡曲線優化 (`smoothTransit`)**：在 EaseInOut 曲線中引入 15% 線性起步與靠站速度基底，確保列車離站起步與進站時擁有平滑且具備視覺動態的平順車速，不再停滯為 0。
  - **客戶端動態速度同步**：在每 tick 推進時為礦車計算並賦予位移速度向量 `velocity`，使客戶端在 60 FPS / 144 FPS 下皆能完美插值平滑補幀，徹底告別微卡頓與瞬移。

## v1.9.0 (2026-08-21)
- **自訂 Hex 十六進位色碼支援**：
  - 路線顏色支援 `#f1f5f5`、`#FF5555`、`#FFF` 等任意十六進位色碼，以及 `&#f1f5f5`、`§x§f...`、`<#f1f5f5>` 格式與原版色碼。
  - **BlueMap 繪圖升級**：線上地圖 3D 軌跡標記支援解析 Hex 色碼並精準以自訂 RGB 渲染。
  - **遊戲內 MiniMessage / Adventure 渲染**：聊天欄、Actionbar、GUI 列表與導航乘車指引同步呈現 Hex 色彩。
  - **GUI 視覺化設定**：在路線管理詳情頁面新增「設定路線顏色」按鈕，支援在聊天欄輸入自訂 Hex 色碼或色碼並即時刷新線上地圖。

## v1.8.0 (2026-08-07)
- **高頻移動監聽與車站檢索效能優化**：
  - 重構 `StopManager.lookupGoldNear`，移除高頻實體世界方塊讀取 (I/O)，改為純記憶體空間快取檢索。
  - `StationDisplayListener` 新增世界車站早期過濾，無金磚世界直接略過處理，大幅降低 TPS 負載。

## v1.7.0 (2026-07-30)
- **站點導覽、路線規劃與自動下車轉乘系統**：
  - 新增所有玩家通用 `/tr` 導覽選單（最近站點、路線總覽、轉乘站一覽與路徑規劃）。
  - 實作 BFS 最優路徑搜尋與轉乘次數計算。
  - 實作即時導航 Session，抵達轉乘站點時自動下車並指引換線。

## v1.6.0 (2026-07-14)
- **BlueMap 整合**：線上地圖即時顯示站點標記與 3D 軌跡，並依照路線顏色渲染。
- **介面優化**：重點站轉乘資訊從 ActionBar 移至聊天欄，並支援動態顯示去回程目的地。
- **路線與軌跡管理升級**：
  - 新增獨立站點排序 GUI，支援左右鍵直覺調整。
  - 支援「多選重點站」，且各站點雙向互聯綁定。
  - 實裝「自動取徑錄製」，兩站間直線不再需要用實體礦車跑，瞬間完成路線錄製。
  - **軌跡儲存架構分離**：將 `lines.yml` 臃腫的座標點資料拆分為獨立檔案，存於 `plugins/atrain/routes/`（格式：`去程ID_回程ID.yml`），大幅減輕設定檔負擔。
  - 將自動尋路演算法從 BFS 升級為高效能的 **A* 演算法**，最高支援 **100,000** 格的超長距離掃描，徹底解決長路線掃描失敗導致移動異常的問題。
  - 錄製段落選擇 GUI 支援直接刪除不需要的段落軌跡。
- **效能優化與修復**：
  - 將每 Tick 全域掃描礦車改為事件觸發的快取清單維護，大幅降低伺服器負載。
  - 修復站點順序變更或合併時可能造成的軌跡錯亂與伺服器崩潰。
  - GUI 存檔還原至主執行緒，避免並行寫入風險 (CME)。
  - 修復去回程月台判定邏輯，現在站內 ActionBar 能夠準確依據玩家所在的月台側（去/回）正確反轉顯示上一站與下一站。
  - 站點編輯 GUI 新增「傳送至另一側月台」的終界珍珠快捷按鈕。
  - 修復同站點多人同時上車時礦車會重疊的問題。現在採用「排隊機制」，若站點已有列車，後續玩家會進入排隊序列，並在上一班列車發車後 1 秒自動發車，實現魚貫而出的流暢體驗。同時修復了狂點站點導致多次排隊發出多班空車的問題。

## v1.5.5 (2026-07-13)
- **原版物理相容**：新增 PDC 實體標籤過濾，徹底解決玩家手動放置的普通礦車被插件強制接管的問題。
- **邏輯修復**：修復終點站玩家上車後仍能開走礦車的漏洞。
- **底層升級**：全面改用 Adventure Component API，移除所有過時 API 以完整相容 Paper 1.21+ (26.2)。
- **路線導引修復**：修復未加載區塊計算路徑的無限迴圈卡死問題、修復座標解碼負數遺失問題、以及修復到站不自動停留與切段的問題。
- **體驗優化**：`/train reload` 提示只會發送給管理員，減少一般玩家干擾；優化 PlayerMoveEvent 金磚站點查詢效能。


- **玩家教學**：新增 `docx/玩家教學.md`；遊戲內 `/train gui` → 教學指南新增「乘車體驗」，並更新快速開始、自動停車等文案以對齊站點導引機制
- **文件整理**：更新日誌移至 `docx/更新日誌.md`；新增 Modrinth 中英文介紹、SEO 文案包
- **建置環境**：Gradle 升至 9.1（支援 Java 25 執行建置）；Shadow 插件改為 `com.gradleup.shadow`；新增 Java 21 toolchain 自動下載
