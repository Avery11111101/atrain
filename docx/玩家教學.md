# atrain 玩家教學

本教學依目前預設機制撰寫（站點導引、自動停車、召車上車皆預設開啟）。服主若關閉部分功能，實際體驗可能不同。

---

## 一、一般玩家：怎麼搭車？

### 1. 看站點資訊

- **站在金磚月台上**（踩在金磚方塊上，不是站在鐵軌上）
- 畫面下方 **動作列（ActionBar）** 會顯示：
  - 上一站
  - 本站
  - 下一站
- 若有設定，還會顯示重點站與行駛方向（例如：台北 → 南下）

> 只是路過月台想看站名，站上去即可，**不需要任何指令**。

### 2. 召喚列車並上車

1. 走到站點的 **鐵軌** 旁（金磚上方的鐵軌）
2. **一般右鍵** 點擊鐵軌（**不要蹲下**）
3. 列車（礦車）會出現在軌道上
4. 預設會 **自動幫你上車**；若沒有，自己點礦車坐上去

> **蹲下 + 右鍵** 是給管理員編輯站點用的，玩家要搭車請用 **一般右鍵**。

### 3. 上車後會發生什麼？

站點若已加入路線，且伺服器開啟 **站點導引**（預設開啟）：

1. **停靠倒數**：畫面提示「○○站 停靠中… N 秒後發車」
2. **發車**：提示「發車 A → B（約 N 秒）」，列車沿路線移向下一站
3. **到站**：提示「抵達 ○○站」，再次停靠，然後往再下一站前進
4. **終點站**：抵達後提示下車，行程結束

整段行程 **不用自己開車**，看著提示等停靠與發車即可。

### 4. 下車

- 按 **Shift** 下車
- 站內召喚的礦車在 **沒有乘客後會自動消失**（避免月台堆滿空車）

### 5. 切換語言

```
/lang zh_TW
/lang zh_CN
/lang en_US
/lang ja_JP
```

## 二、搭車時常見畫面

| 提示 | 意思 |
|------|------|
| 列車已進站：○○，歡迎搭乘！ | 召車成功 |
| 站內已有礦車，請直接上車 | 旁邊已有車，不用重複召 |
| 此站點尚未加入任何路線 | 服主還沒把這站排進路線，無法自動導引 |
| 列車停靠中… N 秒後發車 | 進站停留，倒數結束自動走 |
| 發車 A → B（約 N 秒） | 正在往下一站移動 |
| 已抵達 ○○站 | 到站 |
| 已抵達終點站，歡迎下車 | 這條路線的最後一站 |

## 三、玩家須知

### 不要亂拆方塊

- **金磚站點** 與 **鐵軌下方的鑽石調速塊** 受插件保護
- 沒有管理員權限 **無法拆除**，請勿硬挖

### 蹲下與右鍵的差別

| 操作 | 用途 | 誰能用 |
|------|------|--------|
| 站在金磚上看資訊 | 看上下站 | 所有人 |
| **右鍵** 鐵軌 | 召喚列車 / 上車 | 需有召車權限（服主可開放） |
| **蹲下 + 右鍵** 金磚/鐵軌 | 編輯站點 | 管理員 |
| **右鍵** 調速鑽石塊 | 設定礦車速度 | 管理員 |

### 多台礦車會連成列車

- 月台上若放好幾節相鄰礦車，會 **自動連結成一列**
- 進站停車、發車時是 **整列一起** 動作

### 充能鐵軌加速

- 列車經過 **有紅石通電的充能鐵軌** 時會短暫加速（若服主有開啟此功能）

## 四、服主 / 建造者：怎麼讓玩家能搭？

玩家能順利搭車，至少需要：**站點 → 路線 →（建議）軌道錄製**。

### 步驟 1：建立站點

1. 放置 **金磚**，上方鋪 **任意鐵軌**
2. **蹲下 + 右鍵** 金磚或鐵軌，開啟站點 GUI
3. 設定：
   - 站名
   - 上一站 / 下一站顯示文字（未排路線時手動填；有路線後多由路線決定）
   - **停留時間**（到站停幾秒，預設 4 秒）
   - **行駛時間**（到下一站的秒數，站點導引模式用）
   - 重點站、行駛方向（選填）

相鄰多顆金磚會 **自動合併成同一站**。

### 步驟 2：建立路線並加入站點

1. 執行 `/train` 或 `/train gui` 開啟管理介面
2. **路線管理** → 建立新路線
3. 依 **實際行駛順序** 把各站點加入路線
4. 可開啟 **環線模式**（最後一站的下一站回到第一站）

### 步驟 3：調整各段行駛時間

在 **站點編輯 GUI** 調整「行駛時間 → 下一站」：

- 站點導引不依賴原版礦車物理
- 此數值決定 **這一站到下一站要開幾秒**

### 步驟 4（建議）：錄製軌道

讓列車轉彎時走正確路徑，而不是直線飛過去：

1. `/train gui` → **軌道錄製** 或 路線詳情 → **錄製軌道**
2. 選擇要錄製的路段
3. 到 **起點站** **右鍵** 召喚原版礦車（錄製模式不會觸發一般召車）
4. **自己開車** 沿正確軌道駛到下一站；到站停留後自動進入下一段
5. 全部錄完後停止錄製，軌跡會儲存

之後站點導引會 **沿錄製軌跡** 移動。

### 步驟 5：調速方塊（選用）

- 在 **鐵軌正下方** 放 **鑽石塊**
- 蹲下右鍵或 `/train speed` 設定速度
- 礦車經過上方鐵軌時會加速或減速
- 用於長直線加速、進站前減速等（列車控速模式時生效）

### 步驟 6：開放權限給玩家

預設僅 OP 能召車與建站。若要讓一般玩家搭車：

| 權限 | 用途 |
|------|------|
| `atrain.cart.spawn` | 右鍵召喚礦車 |
| `atrain.station.edit` | 蹲下右鍵建站（通常只給建造者） |

用 LuckPerms 等插件授予即可。

## 六、常見問題

**Q：我右鍵沒反應？**  
A：確認站在已建好的站點鐵軌上；蹲下時右鍵是編輯站點；確認你有召車權限。

**Q：站上看不到站名？**  
A：要踩在 **金磚** 上，不是鐵軌上；確認服主有開啟站點資訊顯示。

**Q：上車後不會自動走？**  
A：此站可能尚未加入路線；或已是終點站；請聯絡服主檢查路線設定。

**Q：列車走直線穿過地形？**  
A：服主尚未錄製該段軌道，導引會用站點間直線路徑；請服主至路線詳情錄製軌道。

**Q：想關掉自動導引，改回自己開礦車？**  
A：服主可在 `config.yml` 將 `cinematic_transit` 設為 `false`，並視需求調整 `train_control`。
