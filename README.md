# atrain

Minecraft 虛擬路線礦車插件 — 用金磚定義站點、用現有鐵軌行駛，不需錄製軌道或複雜設定。

## 功能特色

- **金磚站點**：金磚上鋪任意鐵軌即為停靠站，相鄰金磚自動合併
- **虛擬路線**：在 GUI 排列站點順序，礦車沿實體鐵軌以原版物理行駛
- **停留控制**：每站可設定停留時間，到站後自動發車
- **站名顯示**：站在金磚或鑽石塊上顯示上一站 / 本站 / 下一站
- **圖形管理介面**：`/train gui` 管理路線、站點與速度
- **多語言**：支援繁中、簡中、英文、日文
- **懸浮軌道**：可選的空中軌道模式（預設開啟）

## 安裝

1. 需要 **Paper 1.21+** 與 **Java 21+**
2. 將 `atrain-1.0.jar` 放入 `plugins/`
3. 重啟伺服器
4. 執行 `/train gui` 開啟管理介面

## 快速開始

### 1. 建立站點

1. 放置 **金磚**，上方鋪 **任意鐵軌**
2. 多顆金磚相鄰可連成同一站
3. **蹲下 + 右鍵** 金磚或軌道 → 自動註冊並開啟編輯 GUI
4. 在 GUI 設定站名與停留時間

### 2. 放置站牌（選用）

站在 **金磚** 或旁邊的 **鑽石塊** 上，乘客會看到路線與上下站資訊。

### 3. 建立路線

1. `/train gui` → 路線管理 → 建立新路線
2. 路線詳情 → 加入站點（依行駛順序排列）
3. 可調整速度與環狀路線

### 4. 開始營運

玩家 **右鍵** 金磚上的鐵軌即可搭車，列車會依路線順序停靠各站。

## 指令

| 指令 | 說明 |
|------|------|
| `/train` 或 `/train gui` | 開啟管理介面 |
| `/train lines` | 開啟路線列表 |
| `/train stops` | 開啟站點列表 |
| `/train line create` | 快速建立新路線 |
| `/train line addstop <路線> <站點>` | 將站點加入路線 |
| `/train reload` | 重新載入設定（需管理員） |
| `/lang <語言>` | 切換語言（zh_TW / zh_CN / en_US / ja_JP） |

## 權限

| 權限 | 說明 | 預設 |
|------|------|------|
| `atrain.use` | 搭乘礦車 | 所有人 |
| `atrain.gui` | 開啟管理介面 | 所有人 |
| `atrain.station.edit` | 蹲下右鍵編輯站點 | OP |
| `atrain.create` | 建立路線、管理站點 | OP |
| `atrain.admin` | 重新載入等管理功能 | OP |

## 懸浮軌道（選用）

1. 水平放置 **鐵欄杆 (IRON_BARS)**
2. 下方用普通動力軌導入礦車
3. 礦車自動懸掛行駛
4. `/train gui` 主選單可開關，或編輯 `config.yml` 的 `hang_rail.enabled`

## 設定

`plugins/atrain/config.yml` 主要項目：

| 設定 | 說明 | 預設 |
|------|------|------|
| `settings.cart_speed` | 路線預設速度 | 0.35 |
| `settings.default_dwell_time` | 新站點預設停留（tick） | 80（4 秒） |
| `settings.cart_spawn_delay` | 召喚礦車延遲 | 40 |
| `hang_rail.enabled` | 懸浮軌道開關 | true |
