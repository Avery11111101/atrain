# atrain

智慧礦車路線系統 — 基於 [Metro](https://github.com/CubeX-MC/Metro) 理念重新設計，修正飄線與轉彎回彈問題。

## 功能特色

- **路徑導引**：錄製軌道後自動糾偏，礦車不會飄到別的路線
- **智慧失速恢復**：沿軌道方向補速，轉彎不再撞牆回彈
- **圖形管理介面**：`/train gui` 一站式操作
- **分類教學**：GUI 內建 6 大教學分類，新手也能快速上手
- **懸浮軌道**：內建 TC-HangRail 風格空中軌道（預設開啟，可關閉）

## 安裝

1. 需要 **Paper 26.2**（1.21.x）與 **Java 21+**
2. 將 `atrain-1.0.jar` 放入 `plugins/`
3. 重啟伺服器
4. 執行 `/train gui` 開啟管理介面

## 快速開始

1. 手持 **金斧** 右鍵點擊兩角，框選停靠區
2. `/train gui` → 站點管理 → 建立新站點
3. 站在動力軌上，設定停靠點與發車方向
4. 路線管理 → 建立路線 → 錄製軌道
5. 玩家右鍵動力軌即可搭車

## 指令

| 指令 | 說明 |
|------|------|
| `/train` 或 `/train gui` | 開啟管理介面 |
| `/train record <路線ID>` | 開始錄製軌道 |
| `/train stoprecord` | 結束錄製 |
| `/train reload` | 重新載入設定 |
| `/lang <語言>` | 切換語言 |

## 懸浮軌道

參考 [TC-HangRail](https://www.spigotmc.org/resources/tc-hangrail.39627/)，無需 TrainCarts：

1. 水平放置 **鐵欄杆 (IRON_BARS)**
2. 下方 2 格用普通動力軌導入礦車
3. 礦車自動懸掛行駛
4. `/train gui` 或 `hang_rail.enabled` 可開關

## 與 Metro 的差異

| 項目 | Metro | atrain |
|------|-------|-----------|
| 站間導航 | 原版物理，易飄線 | 路徑點主動糾偏 |
| 失速恢復 | 沿歷史方向硬推 | 沿軌道/路徑方向 |
| 上坡處理 | 強制覆寫速度 | 不干預，避免回彈 |
| 前方阻擋 | 無檢查 | 停止推力 |
